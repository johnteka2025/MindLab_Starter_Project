# MindLab Seed Puzzle Content Scaffold

## Purpose
Seed puzzle content scaffold for Kids, Adults, and Seniors.

## Files
- mindlab-seed-puzzles.v1.json: initial seed puzzle data.
- manifest.json: content scaffold manifest.

## Validation
- JSON must parse successfully.
- Each puzzle must include id, ageCategory, type, difficulty, title, prompt, choices, answer, explanation, and tags.
- Required age categories: kids, adults, seniors.

## Commit Scope
Repository content scaffold only.

MindLab Support

MindLab supports Kids, Adults, and Seniors. This page explains the approved support position for local profile and age-category selection.

Create Local Profile

  1. Open MindLab.
  2. Choose guest play or create a local profile if the feature is available.
  3. Enter a display name only.
  4. Select one age category: Kids, Adults, or Seniors.
  5. Confirm the selection to continue.

Age Category Selection

Age category selection is required after local profile creation. MindLab does not assign a default age category before selection.

  • Kids
  • Adults
  • Seniors

Delete Or Reset Local Profile

MindLab must provide a delete or reset control for local profile data. Use that control to clear display name and selected age category when available.

Data Limits

  • Email and password are not part of the first local profile implementation.
  • Exact age and date of birth are not collected.
  • Backend account creation is not enabled.
  • Analytics identity is not enabled.
  • Service worker user-data caching is blocked.

Offline Support

MindLab includes a minimal offline fallback page. Full offline gameplay is not enabled by this support flow.

Privacy

Review the MindLab Privacy Policy for local profile and age-category data rules.

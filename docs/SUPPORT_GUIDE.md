# MindLab Support Guide

## Project Identity

MindLab is a cognitive game project organized around three age categories:

- Kids: growth and discovery.
- Adults: performance and mastery.
- Seniors: clarity and confidence.

## User-Facing Areas to Check

When reviewing support issues, classify reports into one of these areas:

1. Start screen.
2. Age-category selection.
3. Question presentation.
4. Answer interaction.
5. Scoring.
6. Progress.
7. Start Another Session.
8. Age switching.
9. Runtime loading.
10. Missing-file or blank-screen behavior.

## Local Runtime References

- Backend: `http://localhost:8085`
- Frontend: `http://localhost:8090`

## Support Triage Severity

### Critical

- Game does not launch.
- Backend unavailable.
- Frontend unavailable.
- Missing-file error blocks play.
- Progress or scoring cannot be viewed.

### High

- One age category cannot be completed.
- Age switching fails.
- Question content does not appear.
- Score or progress appears wrong.

### Medium

- UI confusion.
- Copy issue.
- Accessibility concern.
- Minor layout issue.

### Low

- Documentation mismatch.
- Cosmetic text polish.
- Future enhancement idea.

## Scope Rule

Support findings do not authorize fixes automatically.

Create a separate approved repair scope before changing product files.

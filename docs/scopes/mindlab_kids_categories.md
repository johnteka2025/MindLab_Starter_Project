# MindLab Kids Categories

## Category 1 — Color Recognition
- Purpose: Identify basic colors correctly.
- Primary Skill: Visual recognition
- Start Stage: K1

## Category 2 — Shape Recognition
- Purpose: Identify common shapes correctly.
- Primary Skill: Pattern recognition
- Start Stage: K1

## Category 3 — Animal Recognition
- Purpose: Identify animals or traits.
- Primary Skill: Recognition + association
- Start Stage: K1–K2

## Category 4 — Object Recognition
- Purpose: Identify everyday objects.
- Primary Skill: Visual recognition
- Start Stage: K1

## Category 5 — Object Usage
- Purpose: Know object function.
- Primary Skill: Functional understanding
- Start Stage: K2

## Category 6 — Clothing and Body Context
- Purpose: Identify what is worn and where.
- Primary Skill: Context understanding
- Start Stage: K2

## Category 7 — Food and Daily Living
- Purpose: Identify food and daily items.
- Primary Skill: Practical recognition
- Start Stage: K1–K2

## Category 8 — Compare and Choose
- Purpose: Choose best option.
- Primary Skill: Basic logic
- Start Stage: K3

## Category 9 — Sequence and Order
- Purpose: Identify order.
- Primary Skill: Sequential thinking
- Start Stage: K3–K4

## Category 10 — Multi-step Thinking
- Purpose: Combine rules.
- Primary Skill: Early reasoning
- Start Stage: K4

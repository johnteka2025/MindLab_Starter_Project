# Kids batch size rules

Recommended starting rule:
- 1 certified batch per category-stage cell as the minimum closure target.
- 3 to 5 puzzles per pilot batch.
- Increase batch size only after the pilot workflow is stable.

Scaling rule:
- Keep K1-K3 batches small and reviewable first.
- Do not scale K4-K5 until lower-stage balance is accepted.

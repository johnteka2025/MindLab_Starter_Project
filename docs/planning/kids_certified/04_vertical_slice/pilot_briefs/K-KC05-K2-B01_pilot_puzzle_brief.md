# Pilot puzzle brief

## 1. Brief identity
- Certified ID: K-KC05-K2-B01
- Category: KC5
- Stage: K2

- Puzzle title: Match Number to Quantity

## 2. Learning purpose
- Objective: Match numerals to quantities and solve simple one-step comparisons.
- Why it belongs in this category-stage cell: This pilot puzzle directly targets the approved skill focus for KC5 at K2.
- Skills reinforced: category fit, early rule use, confidence, accuracy

## 3. Player experience
- Core interaction: Choose the numeral or set that matches the prompt.
- Prompt wording: Complete the task by choosing the best answer.
- Hint sequence: Count first then compare the totals.
- Feedback / reward: Confirm the quantity relationship in one short sentence.
- Failure handling: Calm retry message followed by hint support on repeated mistakes.

## 4. Content controls
- Reading level: Short instruction sentence with concrete words.
- Time expectation: 30 to 60 seconds.
- Accessibility considerations: Clear number cards large symbols spaced item groups.
- Asset dependencies: Prompt card, answer choices, feedback states, optional audio cue.
- Telemetry expectations: completion rate, first-try success, hint usage, retry count

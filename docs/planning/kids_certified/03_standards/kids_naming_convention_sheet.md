# Kids naming convention sheet

## Certified content
Format:
K-KC##-K#-B##-P##

Example:
K-KC01-K1-B01-P01

Where:
- KC## = Kids category code
- K#   = stage
- B##  = batch number inside the category-stage cell
- P##  = puzzle number inside the batch

## Re-certified legacy content
Format:
K-LEGACY-RC-KC##-K#-B##-P##

Rule:
Never reuse the old 01-55 numbering as certified progress.

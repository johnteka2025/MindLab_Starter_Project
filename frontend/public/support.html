MindLab Support

Last updated: 2026-05-24

Use this page for MindLab support, issue reporting, and release-readiness review. MindLab supports Kids, Adults, and Seniors game modes.

Recommended Support Information to Provide

  • Your device and browser
  • The game mode used: Kids, Adults, or Seniors
  • The screen where the issue happened
  • What you expected to happen
  • What actually happened
  • A screenshot, if available

Issue Types

  • App loading issue
  • Game question issue
  • Score or progress issue
  • Age category issue
  • Accessibility issue
  • Privacy or support question
  • Other

Important Limits

MindLab is not a medical, diagnostic, treatment, prevention, or guaranteed cognitive-improvement product.

MindLab Privacy Policy

Last updated: 2026-05-24

MindLab provides game modes for Kids, Adults, and Seniors. MindLab is not a medical, diagnostic, treatment, prevention, or guaranteed cognitive-improvement product.

Information We Use

MindLab may use basic operational information needed to run the game experience, such as selected game mode, gameplay progress, answers, scores, and technical information required to keep the app working.

Analytics

Third-party analytics are disabled by default unless a separate analytics provider implementation is approved, disclosed, and configured.

Data Sales

MindLab does not sell user data.

Kids Mode

Kids mode is an age-category gameplay mode. It is not a verified child-account system and should not be treated as a substitute for parent, guardian, school, medical, or professional review.

Data Retention

MindLab should retain only operational data required for app function, testing, troubleshooting, or maintenance.

Support

For help, visit the MindLab support page: Support.

Policy Updates

This policy may be updated when the app changes, when a store listing changes, or when a new analytics or support provider is approved.

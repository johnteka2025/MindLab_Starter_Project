MindLab Privacy Policy

Effective date: 2026-06-06

Overview

MindLab is a simple game and practice experience with local profile support. For the approved internal testing scope, MindLab uses local profile information on the user's device to remember the selected game category.

Information Used

MindLab may use the following local-only information:

  • Local profile name
  • Selected age category label: Kids, Adults, or Seniors

Information Not Collected in the Approved Scope

For the approved internal testing scope, MindLab does not include:

  • Email collection
  • Password collection
  • Birthdate collection
  • Exact-age collection
  • Online account creation
  • Cloud sync
  • Analytics
  • Payment flow
  • Advertising system
  • Medical or therapy assessment

Local Storage

MindLab may store the local profile on the user's device so the user can continue the selected profile experience.

Data Sharing

No data-sharing implementation has been added in the approved internal testing scope.

Children and Age Categories

MindLab uses broad age category labels only for game mode selection. MindLab does not collect birthdate or exact age in the approved internal testing scope.

Health and Medical Disclaimer

MindLab is a game and practice experience. MindLab is not medical advice, diagnosis, therapy, clinical assessment, professional care, or a guarantee of improvement.

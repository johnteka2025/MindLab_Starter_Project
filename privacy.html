MindLab Privacy Policy

MindLab supports Kids, Adults, and Seniors. This page explains the current privacy position for the local profile and age-category selection flow.

Local Profile Data

MindLab may allow a local profile on the user's device. The first approved profile model is local-only and does not create a backend account.

  • Display name may be stored locally on the user's device.
  • Selected age category may be stored locally on the user's device.
  • Local profile identifier may be stored locally for continuity.
  • Created and updated timestamps may be stored locally.

Data Not Collected In First Implementation

  • Exact age is not collected.
  • Date of birth is not collected.
  • Email and password are not collected in the first implementation.
  • Real name, address, phone number, school name, payment data, and precise location are not collected.
  • Analytics identity is not enabled.

Kids Category

If the Kids category is selected, MindLab does not require email, exact age, date of birth, or real name in the first implementation. Kids category data remains limited to the local profile and selected age category unless a separate privacy review approves more.

Age Categories

MindLab uses age category selection to route users to the correct experience.

  • Kids
  • Adults
  • Seniors

No default age category is assigned before user selection.

Delete Or Reset Local Profile

MindLab must provide a way to delete or reset the local profile before the local profile flow is treated as complete.

Offline And Service Worker Limit

The service worker is limited to minimal offline fallback support. It must not cache local profile data, account data, analytics identity, or future sign-up data.
